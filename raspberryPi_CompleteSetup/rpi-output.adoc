|7 |Test: DNS, DHCP scope |Connect/disconnect PC & RPi |Ensure DHCP leases via Pi-hole

[cols="1%,19%,40%", options="header", caption="", title="RPI SSH"]
|===
|# |Prerequisites |One-liner Commands / Instructions
|1 |Connect RPi and Windows to same LAN |Verify both IPs: `ipconfig` on Windows, `hostname -I` on RPi
|2 |Enable SSH on Pi |`sudo systemctl enable ssh && sudo systemctl start ssh`
|3 |Find RPi IP (from Windows) |Use router admin panel or run: `ping raspberrypi.local`
|4 |SSH into RPi from PowerShell |`ssh pi@<rpi_ip>` (default user: pi, default pass: raspberry)
|5 |Enable passwordless sudo on RPi |`sudo visudo` → add: `pi ALL=(ALL) NOPASSWD: ALL`
|6 |Test sudo from Windows PowerShell |`ssh pi@<rpi_ip> "sudo apt update"` → should not prompt for pass
|7 |Optional: Create PowerShell alias |`Set-Alias -Name rpi -Value "ssh pi@<rpi_ip>"` → then use: `rpi "sudo systemctl restart nginx"`
|8 |Enable Wake-on-LAN (if supported) |Check `ethtool eth0 | grep Wake-on` → use `wakeonlan <mac>` from Windows
|9 |Auto-assign static IP to RPi |Edit `/etc/dhcpcd.conf` or reserve via router DHCP lease
|10|(Alt) Hostname-based access |Add `192.0.2.x raspberrypi` to `C:\Windows\System32\drivers\etc\hosts`
|===

[cols="1%,35%,64%",options="header", caption="", title="Optional Remote Desktop Access"]
|===
|# |Prerequisites |One-liner Commands / Instructions
|1 |Install X11VNC on RPi |`sudo apt install -y x11vnc`
|2 |Set VNC password |`x11vnc -storepasswd` → saves to `~/.vnc/passwd`
|3 |Start VNC server manually |`x11vnc -usepw -forever -display :0`
|4 |(Optional) Auto-start VNC |`sudo nano /etc/systemd/system/x11vnc.service` → create service
|5 |Enable service |`sudo systemctl enable x11vnc && sudo systemctl start x11vnc`
|6 |Connect via VNC Viewer |Install https://www.realvnc.com → connect to `<rpi_ip>:5900`
|7 |For lightweight GUI (if headless) |Install: `sudo apt install xfce4 xfce4-goodies lightdm`
|8 |Set default X session |`echo "exec startxfce4" > ~/.xsession`
|9 |For RDP instead of VNC |Install XRDP: `sudo apt install xrdp` → connect via Windows RDP to `<rpi_ip>:3389`
|===

[cols="1%,29%,70%",options="header", caption="", title="DHCP & DNS"]
|===
|# |Prereq |Extra
|01 |Update system and enable SSH |`sudo apt update && sudo apt upgrade -y && sudo raspi-config`
|02 |Static IP + Hostname |Edit `/etc/dhcpcd.conf`, set static IP. Set hostname via `raspi-config > Network Options`.
|03 |Install Pi-hole |`curl -sSL https://install.pi-hole.net \| bash`
|04 |Custom DNS filtering (RethinkDNS) |Export filters from RethinkDNS to hosts format, add to Pi-hole blacklist.
|05 |Set up DNS server | `sudo apt install unbound`
|06 |Enable DHCP via Pi-hole |Web UI: Settings > DHCP > Enable. Disable DHCP on router.
|07 |Configure firewall (UFW) |`sudo apt install ufw && sudo ufw default deny incoming && sudo ufw allow ssh && sudo ufw allow 53,80,443/tcp && sudo ufw enable`
|08 |Deploy local server (Flask/Node.js/Nginx) |`sudo apt install nginx`
|09 |Connect RPi to PC via USB Ethernet gadget |Edit `/boot/config.txt` and `/boot/cmdline.txt`, configure USB OTG in `/etc/network/interfaces`.
|10 |Share RPi's Wi-Fi + Bluetooth |Install `dnsmasq`, `hostapd`, `bluez`, setup NAT, enable IP forwarding in `/etc/sysctl.conf`.
|11 |HDMI output to TV |Configure `/boot/config.txt`. `sudo apt install vlc`, use chromium, spotifyd, or motrix.
|12 |Install Syncthing (LAN) |Add repo and `sudo apt install syncthing`
|13 |Syncthing (Remote Access) |Allow ports, use Tailscale/ZeroTier.
|14 |Hardening: Fail2Ban, firewall rules |`sudo apt install fail2ban`, configure `jail.local`, use rkhunter
|15 |Data storage |Mount SSD via `/etc/fstab`, use `rsync`, `borgbackup`, or `restic`
|16 |Extra: VPN (WireGuard) |`sudo apt install wireguard`, configure and enable service.
|17 |Extra: Docker + Portainer |Install Docker, run Portainer container.
|===
